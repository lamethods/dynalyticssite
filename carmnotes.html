CarmNotes · Analysis without installation

A notebook you can carry, open, and reproduce.

CarmNote is a family of interactive notebooks for statistical and network analysis. Each notebook is a self-contained HTML file that runs in the browser—even offline—with the analysis, results, and narrative kept together.
